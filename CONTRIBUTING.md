# Contributing

Thank you for helping improve Google Search Console MCP.

## Before opening a pull request

1. Open an issue for substantial behavior or API changes.
2. Keep changes focused and preserve secure defaults.
3. Add or update tests.
4. Run `npm run check`.
5. Use clear commit messages.

Never add credentials or private Search Console response data to fixtures, issues, commits, or logs.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
